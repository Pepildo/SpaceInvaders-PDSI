# 👾 Space Invaders

Um jogo inspirado no clássico **Space Invaders**, desenvolvido em linguagem C como projeto da disciplina **Programação e Desenvolvimento de Software I (PDS I)** da Universidade Federal de Minas Gerais (UFMG).

O projeto consiste em recriar a experiência do arcade clássico, aplicando conceitos de programação, lógica, manipulação de eventos e desenvolvimento de aplicações gráficas.

## 🎮 Sobre o jogo

O jogador controla um canhão espacial e precisa eliminar uma formação de naves inimigas antes que elas alcancem a parte inferior da tela.

O jogo conta com diferentes tipos de inimigos, sistema de pontuação, recorde de pontos, efeitos sonoros e elementos visuais personalizados, proporcionando uma experiência mais próxima dos jogos clássicos de arcade.

## ✨ Funcionalidades

- **Movimentação do jogador:** controle do canhão para a esquerda e direita.
- **Sistema de disparos:** disparos de projéteis para eliminar os inimigos.
- **Inimigos com diferentes pontuações:** três categorias de naves, com valores distintos de pontos.
- **Dificuldade progressiva:** as naves aumentam sua velocidade conforme avançam pela tela.
- **Detecção de colisões:** identificação de impactos entre projéteis, inimigos e jogador.
- **Sistema de pontuação:** contabilização dos pontos conforme os inimigos eliminados.
- **Recorde persistente:** salvamento e leitura da maior pontuação utilizando arquivo de texto.
- **Condições de vitória e derrota:** identificação do resultado da partida.
- **Efeitos sonoros:** sons de disparos, explosões, vitória e derrota.
- **Recursos gráficos:** imagens personalizadas para personagens, inimigos, menu e cenário.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| `ENTER` | Iniciar o jogo |
| `←` | Movimentar para a esquerda |
| `→` | Movimentar para a direita |
| `ESPAÇO` | Atirar |
| `ESC` | Sair do jogo |

## 🛠️ Tecnologias utilizadas

- **C:** linguagem principal utilizada no desenvolvimento.
- **Allegro 5:** biblioteca gráfica utilizada para criação da janela, renderização de imagens, gerenciamento de eventos, áudio e elementos visuais.
- **Git:** versionamento e organização do desenvolvimento.

### Conceitos aplicados

Durante o desenvolvimento, foram trabalhados conceitos fundamentais da programação:

- Estruturas de dados (`struct`).
- Matrizes e vetores.
- Funções e modularização.
- Estruturas de repetição e condicionais.
- Manipulação de arquivos para persistência de dados.
- Lógica de colisão entre objetos.
- Gerenciamento de eventos e entrada do usuário.
- Controle de tempo e atualização de frames (60 FPS).

## 🖼️ Recursos visuais e sonoros

O projeto utiliza imagens personalizadas para o cenário, menu inicial, canhão e diferentes tipos de naves inimigas.

Também conta com arquivos de áudio específicos para ações e acontecimentos durante a partida, incluindo disparos, explosões, vitória e derrota.

## 🚀 Execução

Para executar o projeto, é necessário ter um compilador C e a biblioteca **Allegro 5** instalados e configurados no ambiente.

Os arquivos de imagens, fontes e áudio utilizados pelo jogo também devem estar disponíveis no diretório esperado pela aplicação.
